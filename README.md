# Smart Urban Traffic Management 🚦

A web-based project focused on understanding urban traffic problems and exploring how modern technologies can help improve traffic management.

The project explains smart traffic management concepts and includes an interactive traffic monitor to demonstrate traffic conditions across selected Indian cities.

## Features

- **Traffic Problem Analysis:** Understand common causes and effects of urban traffic congestion.
- **Smart Traffic Management:** Learn how modern technologies can improve traffic flow.
- **Traffic Strategies:** Explore six different approaches to managing urban traffic.
- **Interactive Traffic Monitor:** View traffic information for selected locations across seven Indian cities.
- **Traffic Statistics:** Check current speed, free-flow speed, congestion index and estimated travel time.
- **India Context:** Explore government initiatives and challenges related to traffic management in India.
- **Future Technologies:** Learn about AI, connected vehicles and intelligent transportation systems.
- **References:** Access the sources used for the project.

## Tech Stack

- React.js
- TypeScript
- Tailwind CSS
- Vite
- Google Maps
- Leaflet
- TomTom Traffic Flow API
- Lucide React

## Project Purpose

This project was developed to explore the role of technology in solving urban traffic-related problems. It combines research-based information with an interactive web interface to make smart traffic management concepts easier to understand.
